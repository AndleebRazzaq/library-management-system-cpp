# library-management-system-cpp
Console-based Library Management System implemented in C++ .

## Overview

This project simulates basic library operations such as adding books, issuing books, returning books, and managing records. The system is structured using classes and modular file organization to demonstrate strong C++ programming fundamentals.

## Features

- Add new books
- Display book records
- Issue books
- Return books
- Search for books
- File-based data storage
  
## Concepts Demonstrated

- Object-Oriented Programming (OOP)
- Class design & encapsulation
- Constructors & member functions
- Header and source file separation
- File handling (fstream)
- STL usage (vector, string)

---

## Tech Stack

- C++
- Standard Template Library (STL)
